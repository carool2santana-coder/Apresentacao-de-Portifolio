# Seção institucional de um site de floricultura

**Autora:** Caroline de Santana  
**Ano:** 2023  
**Contexto:** projeto acadêmico em equipe — Programação Web  
**Minha responsabilidade:** seção institucional  
**Tecnologias do projeto:** HTML, CSS e JavaScript  
**Ambiente de desenvolvimento:** Visual Studio Code.

## Contexto e objetivo

O projeto acadêmico consistiu no desenvolvimento de um site de floricultura em equipe.

Minha responsabilidade foi a seção “Instituição”, destinada à apresentação da organização no site. O objetivo desse recorte era organizar o conteúdo institucional em uma página web e integrar minha contribuição ao trabalho do grupo.

## Minha atuação

- Desenvolvi a seção institucional.
- Trabalhei com o conteúdo e a estrutura dessa parte do site.
- Participei da construção coletiva, dentro da responsabilidade atribuída a mim.
- Utilizei o Visual Studio Code no desenvolvimento.

A autoria do site completo foi coletiva. Minha contribuição apresentada neste case se limita à seção institucional.

## Entrega

A entrega relatada foi a seção institucional do site acadêmico.

O projeto utilizou HTML, CSS e JavaScript. Não são atribuídos a este case recursos de checkout, pagamentos, banco de dados ou outras funcionalidades não confirmadas.

## Resultados e limites

A experiência proporcionou prática de desenvolvimento web básico e participação em um projeto com divisão de responsabilidades.

Nesta versão do portfólio, não há confirmação de publicação do site em produção, métricas de acesso ou resultados de testes de usabilidade.

## Competências demonstradas

- Compreensão de um escopo definido.
- Organização de conteúdo institucional.
- Desenvolvimento web básico.
- Colaboração em equipe.
- Delimitação da contribuição individual em uma entrega coletiva.

## Aprendizados

O trabalho contribuiu para minha compreensão da relação entre conteúdo, estrutura de páginas e implementação.

Também reforçou a importância de definir as responsabilidades de cada integrante e compreender como cada parte contribui para o resultado do grupo.

Para minha formação em análise de sistemas, a experiência oferece uma base prática para dialogar sobre o que uma página precisa apresentar e como esse conteúdo se transforma em uma entrega.
