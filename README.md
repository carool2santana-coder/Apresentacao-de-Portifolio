## Sobre esta documentação

Os cases foram organizados a partir das minhas experiências e dos materiais disponíveis. Minha contribuição individual e o estágio de cada projeto estão identificados nos documentos.

Resultados qualitativos são apresentados como observações da autora. Não são atribuídos percentuais ou ganhos financeiros sem medição.

A organização e a redação deste portfólio contaram com apoio de inteligência artificial. As tabelas de necessidades e os fluxos foram documentados retrospectivamente; propostas de requisitos ainda dependem de validação pelos envolvidos.
